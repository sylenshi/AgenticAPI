## 文档 v2.5（2026-11-07，实施于系统 v0.14.1）

首轮实战复盘修复（v0.14.0 会话导出功能交付的第一份真实记录暴露，属 bugfix）：

- **redact 两处误伤**（v0.10.0 起潜伏）：`max_tokens` 等业务统计字段键名被 "token" 子串误掩——新增精确豁免集；`apiKeyHint` 尾 4 位提示被二次掩码——已是掩码形态的值直接放行；
- **web_search 必然整体折叠**：工具侧按字符截 6000，8KB 截断器按字节计（中文 3 字节/字符）必超限——修为 search_service 暴露 `max_results` / `snippet_limit`，Agent 侧 6 条 × 220 字，工坊默认配额不变；
- **提示与文案清理**：过时的"导出类工具"说法、`list_upstream_models` 404 提示前导分隔符与 summary 重复、沙箱描述补"仅国内站点可达（联网核实用 web_search）"；
- 无需 DDL。

## 文档 v2.4（2026-11-07，实施于系统 v0.14.0）

**安全用钥通道 + 会话导出**（修复"需钥上游操作全做不了"：模型发现只能沙箱裸调 /models 无钥必 401、声明列表外候选无法试拨、凭证到期只能播报不能处置）：

- **方案**："按名字引用凭证"取代"持有凭证"——需钥上游操作一律后端代持密钥执行（密钥仅在服务端注入请求头，不进对话上下文 / 审批卡 / 消息表 / 沙箱）；
- **工具 23→25**（L0 15 / L1 3 / L2 7）：新增 `list_upstream_models`（L0，代持密钥拉上游 /models + 声明列表差集对照）、`test_channel` 放宽可试拨列表外候选名（`notInDeclaredList` 标注）、恢复 `rotate_channel_key`（L2，审批卡只显尾 4 位）；
- **指引修正**：补"需钥操作走站内工具"与模型发现标准路径（list_upstream_models → 404 时 test_channel 逐名试拨），去除与密钥规则自相矛盾的沙箱拉清单指引；
- **会话导出**：`GET /maintain-agent/sessions/{id}/export`（Markdown：正文 / 工具调用 / 结果 / 审批轨迹，取落库脱敏版本），右栏"导出"按钮自动下载；密钥口径修正为"密钥存于 `llm_channels` 本体，日志/消息/界面全掩码"；
- 无需 DDL。

## 文档 v2.3（2026-11-07，实施于系统 v0.13.0）

**任务与请求解耦**（修复"整个循环寄生在单个 SSE 请求里，刷新 / 断网即中断，且切换会话会主动掐断任务"）：

- `POST /chat` 只提交任务（服务端 asyncio Task 托管，同会话并发 409）；新增 `GET /sessions/{id}/stream` 订阅（回放缓冲 + 实时跟随 + 15s 心跳防代理超时）与 `POST /sessions/{id}/stop`；
- 会话列表带 `running` 标记，进入 running 会话自动订阅续看；前端移除"切换会话自动停止"，停止按钮改取消服务端任务；
- 边界：任务结束清空回放缓冲（历史走 DB）；执行中刷新该轮未落库增量不回放；服务重启仍丢任务（悬挂 tool_calls 由断链修复兜底）；
- 无需 DDL。
