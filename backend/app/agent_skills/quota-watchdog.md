# 额度水位研判 SOP

## 数据获取

`get_upstream_usage`（scope=all，antigravity 走缓存秒回）+ `get_token_expiry`。

## 解读口径（与运维页一致）

- 每个上游看三个窗口：**5 小时滚动窗口**（短期突发）、**周窗口**（中期趋势）、**月窗口**（预算水位，仅部分上游提供）；
- 已用比例 = 已用量 / 总额度；重置时间在窗口末尾；
- Antigravity（Gemini）只有 5 小时 + 周窗口，无月窗口，缺桶时按"无对应限额"陈述，不臆测。

## 预警阈值

| 水位 | 阈值 | 话术 |
|---|---|---|
| 🟠 橙色 | ≥ 80% | "接近耗尽，建议控制调用频率或准备补充" |
| 🔴 红色 | ≥ 95% | "即将耗尽，高概率出现 429/402 拒绝" |

## 临期凭证提醒

`get_token_expiry` 中 daysLeft ≤ 7 的凭证单独列出：`⚠ 凭证 X 将于 Y 后过期（剩 N 天），请及时更新`。

## 报告模板

```
## 额度水位速览
| 上游 | 5h 窗口 | 周窗口 | 重置时间 |
（超阈值的水位加预警标记与建议）
```
